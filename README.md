## Описание проекта

Сайт представляет студию маникюра/педикюра и наращивания ресниц, включает:

- визуально насыщенный hero-блок;
- секции услуг, преимуществ, портфолио и контактов;
- интерактивные элементы для повышения вовлеченности;
- оптимизацию для статического хостинга (GitHub Pages).

## Технологии

- `Next.js 16` (App Router, static export)
- `React 18` + `TypeScript`
- `Tailwind CSS`
- `GSAP` для анимаций
- `Vitest` + `Testing Library` для тестов

## Функциональность

- Кастомный динамический курсор с контекстным режимом.
- Модальные окна записи и запроса стоимости.
- Ленивая загрузка карты Яндекс.
- Service Worker с базовым кешированием статических ресурсов.
- Поддержка статического экспорта:
  - `output: "export"`
  - автоматическая подстройка `basePath`/`assetPrefix` под GitHub Pages.

## Структура проекта

```text
app/                 # layout, page, глобальные стили
components/          # UI-компоненты и интерактив
lib/                 # утилиты (cursor, scroll, reveal)
public/img/          # статические изображения
public/sw.js         # service worker
tests/               # unit/integration тесты
.github/workflows/   # CI/CD workflow для GitHub Pages
```

## Локальный запуск

Требования:

- `Node.js 20+`
- `npm 10+` (рекомендуется)

Установка и запуск:

```bash
npm ci
npm run dev
```

Открыть в браузере: `http://localhost:3000`.

## Сборка и публикация

### Production build

```bash
npm run build
```

Команда создаёт статическую сборку в папке `out/`.

### GitHub Pages

В проекте уже добавлен workflow: `.github/workflows/deploy-pages.yml`.

1. Откройте репозиторий на GitHub.
2. Перейдите в `Settings -> Pages`.
3. В источнике публикации выберите `GitHub Actions`.
4. Запушьте изменения в ветку `main`.
5. Дождитесь успешного выполнения workflow `Deploy To GitHub Pages`.

## Тестирование

Запуск всех тестов:

```bash
npm test
```

Запуск в watch-режиме:

```bash
npm run test:watch
```
