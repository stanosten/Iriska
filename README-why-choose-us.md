# Блок «Почему выбирают нас» (WhyChooseUs.tsx)

## Описание
Интерактивный блок для главной страницы салона "Ири&Ка". Включает текстовый контент, маркированный список преимуществ, адаптивное изображение (WebP с Fallback на JPG) и анимированные счетчики статистики.

## Технические особенности
- **Верстка:** Семантический HTML (`<section>`, `<h2>`, `<p>`, `<ul>`, `<li>`, `<figure>`, `<picture>`).
- **Стилизация:** Tailwind CSS (строгое соответствие: текст `#333`, шрифты 16px/24px, межстрочный интервал 1.5).
- **Анимация счетчиков:** Написана на **чистом JavaScript** (`requestAnimationFrame` + `IntersectionObserver`) без использования сторонних библиотек. Выполняется 1 раз при скролле.
- **Изображения:** Ленивая загрузка (`loading="lazy"`), тег `<picture>` для поддержки WebP.

## Подключение
Компонент уже интегрирован в главную страницу. Если потребуется переиспользовать его в другом месте:

1. Импортируйте компонент:
```tsx
import WhyChooseUs from "@/components/WhyChooseUs";
```

2. Вставьте в JSX:
```tsx
<WhyChooseUs />
```

## Требования к ресурсам
Убедитесь, что в папке `public/img/` находятся файлы:
- `studio.webp` (основное изображение)
- `studio.jpg` (fallback-изображение для старых браузеров, не поддерживающих WebP)

## Доступность (a11y)
- Блок связан с заголовком через `aria-labelledby`.
- Счетчики имеют `aria-label` для скринридеров и `tabIndex={0}` для навигации с клавиатуры.
- Цветовой контраст текста `#333` на белом фоне (`#FFF`) составляет 12.6:1, что превосходит стандарт AAA (≥ 7:1).
